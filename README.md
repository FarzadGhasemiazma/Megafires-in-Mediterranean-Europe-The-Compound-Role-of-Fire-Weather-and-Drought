# Megafires in Mediterranean Europe: The Compound Role of Fire Weather and Drought

Data and code associated with the study of how fire weather and drought relate to wildfire growth in Mediterranean Europe.

## Data and code

The archived data and code are available on Zenodo:

- [Version record: 10.5281/zenodo.18934902](https://doi.org/10.5281/zenodo.18934902)
- [Concept record: 10.5281/zenodo.18934901](https://doi.org/10.5281/zenodo.18934901)
